# Portfolio de Víctor Jara Barriga

Portfolio personal estático preparado para publicarse con GitHub Pages.

## Vista previa local

Abre `index.html` en el navegador o inicia un servidor local en esta carpeta.

## Publicación en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta a la rama principal.
3. En **Settings → Pages**, selecciona **Deploy from a branch**.
4. Elige la rama principal y la carpeta raíz (`/`).

## Archivos principales

- `index.html`: contenido y estructura.
- `styles.css`: diseño adaptable a móvil y escritorio.
- `script.js`: navegación, animaciones y visor del CV.
- `assets/`: fotografía, currículum y vista previa.

Para actualizar el currículum en el futuro, sustituye `assets/curriculum-victor-jara.pdf` y genera de nuevo `assets/cv-preview.webp` manteniendo esos nombres.
